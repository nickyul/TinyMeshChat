# Безопасность

## Сообщение об уязвимости

Не публикуйте сведения об активно эксплуатируемой уязвимости в обычном issue. Используйте приватный security advisory репозитория GitHub и укажите затронутую версию, платформу, шаги воспроизведения и возможное влияние.

## Модель доверия

- чат и голос передаются напрямую между участниками через WebRTC;
- STUN раскрывает сетевые адреса, но не переносит сообщения;
- история сообщений и аудиозаписи не сохраняются;
- update-клиент доверяет публичному GitHub repository, HTTPS и штатному Velopack feed;
- равные, старые, повреждённые и неподходящие текущему каналу packages отклоняются Velopack.

Собственной криптографической подписи update manifest сейчас нет. Компрометация GitHub repository или release credentials позволит подменить update feed. До внедрения Authenticode и Apple Developer ID/notarization сборки также могут вызывать предупреждения операционной системы о неизвестном издателе.
